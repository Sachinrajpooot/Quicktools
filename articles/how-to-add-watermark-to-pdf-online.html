How to Add a Watermark to a PDF Online

Open the QuickTools24 PDF Watermark tool

A watermark is a short label or image placed on a document to show its status, source or branding. You might mark a working copy as DRAFT, label a handout as SAMPLE, or place a company logo on a report before sharing it.

This guide explains how to add a text or image watermark to a PDF, choose where it appears, apply it to selected pages and check the finished file. It also explains an important limitation: a watermark is a visible document label, not a substitute for PDF security.

Before you begin: keep an unchanged copy of the original PDF. The QuickTools24 watermark tool creates a new marked copy and does not provide a button to remove a watermark from that copy.

Text watermark or image watermark: which should you use?

Choose the type that communicates the information clearly without making the page difficult to read.

  • Text watermark: useful for words such as DRAFT, SAMPLE, REVIEW COPY or a short organisation name. You can choose the position, opacity, rotation, font size and text colour.
  • Image watermark: useful for a logo or simple brand mark. QuickTools24 accepts PNG and JPEG image files. A transparent PNG is often a good choice for a logo because the background of the image can remain transparent.

Keep the wording short. A large paragraph or detailed image can compete with the document itself, especially on forms and scanned pages.

How to add a watermark to a PDF with QuickTools24

  1. Open the PDF Watermark tool. Visit Add PDF Watermark in your browser.
  2. Select your PDF. Choose the file from your phone, tablet or computer. Let the document load before changing the settings.
  3. Choose the watermark type. Select Text to write a label, or select Image to use a PNG or JPEG logo. If you choose text, enter the exact wording you want to appear.
  4. Set the position. Choose from nine positions: top, middle or bottom, each aligned left, centre or right. A corner position is often suitable for a logo; a centred diagonal label can work for a DRAFT copy.
  5. Adjust the appearance. For text, choose a readable font size and colour. Set the rotation angle if you want a diagonal mark. Adjust opacity so the watermark is visible but does not make the page hard to read. The tool's initial opacity value is 0.22; use it as a starting point and adjust after checking the output.
  6. Choose which pages to mark. Leave the page-range field blank to apply the watermark to all pages. To mark selected pages, enter page numbers and ranges such as 1, 3-5, 8. Page numbering starts with 1 for the first PDF page.
  7. Process and download the new PDF. Start the process, save the output and open it in a PDF viewer. Check the first page, a middle page and the last page, as well as the pages around any selected range.

How to choose a readable watermark

Use opacity carefully

A watermark that is too faint may be missed; one that is too dark can distract from the document. Start near the tool's default opacity of 0.22, then make small adjustments. Check the result at normal screen zoom and, when the PDF will be printed, on a test print if the document is important.

Keep the mark away from essential details

QuickTools24 draws the watermark over the existing page content. It can overlap text, a signature, a stamp, a QR code or a form field if you place it on top of that area. Choose a quieter part of the page whenever possible. Review pages with different layouts separately instead of assuming one position will suit every page.

Use a clean logo image

For a logo, prefer a simple PNG or JPEG with good contrast. A transparent PNG can avoid a solid rectangular background around the logo. Avoid a very detailed image or tiny lettering that becomes difficult to recognise when scaled down.

Apply a watermark to only some pages

You may not need a watermark on the cover, contents page or a blank divider. In the page-range field, enter the page numbers that should receive the mark. For example, 2-8 selects a continuous range, while 1, 4, 7-9 selects individual pages and a range. Leave the field empty when the mark should appear throughout the PDF.

PDF page numbers in this field refer to the physical order of pages in the file: the first page is 1, the second is 2, and so on. They may not match printed numbers already visible on the pages.

What a PDF watermark does—and what it does not do

A watermark helps a reader recognise a document's status or source. It can make a review copy easier to distinguish from a final copy and can provide visible branding. Adobe describes watermarks as fixed text or images added to PDF pages for purposes such as ownership, branding and confidentiality.

A watermark does not encrypt a PDF, require a password, prevent screenshots or stop every form of copying or editing. Anyone who can access a document may still be able to copy its contents. Do not rely on a watermark alone to protect confidential information or to prove that a document is authentic. When access restrictions are needed, use suitable password and permission settings in a trusted PDF security application.

A watermark is also different from a digital signature. A visible name or logo does not cryptographically verify who created a PDF or whether it has changed since signing.

Useful workflows with other PDF tools

  • Combine files first: when several reports should carry the same mark, use Merge PDF first, then apply one watermark to the combined document. See the PDF merging guide.
  • Add information in a margin: for recurring header or footer text, use Add PDF Header & Footer rather than placing a large watermark across the page.
  • Mark an image instead of a PDF: use Image Watermark when your source is a photo rather than a PDF document.
  • Reduce a large output: the PDF Compressor can create a smaller rasterised copy. Because rasterisation can affect selectable text and fine detail, inspect the compressed result before using it.

Use the tool on a phone

You can open the QuickTools24 tool in an up-to-date mobile browser, choose the PDF from your device's file picker and set the available options. A large or image-heavy PDF may take longer to process or may be limited by the memory available to the browser. Keep the original file until you have checked the downloaded copy.

Frequently asked questions

Can I add a watermark to only selected PDF pages?

Yes. Enter individual page numbers or comma-separated ranges such as 1, 3-5, 8. Leave the page-range field blank to apply the watermark to every page.

Can I use my logo as a PDF watermark?

Yes. QuickTools24 accepts PNG and JPEG image watermarks. A transparent PNG is useful for a logo because it can preserve transparent areas.

Does a watermark stop people from copying a PDF?

No. A watermark labels or identifies a document, but it does not encrypt the PDF or control who can open, copy, print or edit it. Use appropriate security settings when access control is required.

Can a watermark cover existing text?

It can. QuickTools24 draws the watermark over the page content, so choose a clear position, use a suitable opacity and inspect the result before sharing.

Can I remove a watermark later?

The QuickTools24 tool does not include a remove-watermark control. Keep the original PDF before editing so you can return to an unmarked copy.
