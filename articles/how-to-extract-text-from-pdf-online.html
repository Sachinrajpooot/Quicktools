How to Extract Text from a PDF Online

Copying words from a PDF depends on how the document was made. Some PDFs contain real, selectable text. Others are scanned page images that only look like text. The right method depends on which type of file you have.

This guide shows how to extract selectable text with QuickTools24, how to recognise an image-only scan, and when you need optical character recognition (OCR) before you can copy the words.

Start with the right tool: The QuickTools24 Extract PDF Text tool reads text already stored in a PDF and creates a separate TXT file. It does not perform OCR on page images, so scanned pages without a text layer need an OCR step first.

What does extracting text from a PDF mean?

A text-based PDF stores characters that a PDF viewer can usually search, select and copy. A scanned PDF may instead contain a photograph or image of each page. The letters are visible to your eyes, but the file may not contain the underlying words as text.

Text extraction reads the words that are already present in the document and places them in another format, such as a plain text file. OCR is different: it examines page images and attempts to recognise the letters and words in those images.

How to tell whether a PDF is scanned or text-based

Before choosing an extraction method, test a page that contains a normal paragraph:

  • Try to select a sentence. Drag across a line in your PDF viewer. If individual words can be highlighted, the page likely has a text layer.
  • Copy and paste a short line. Paste it into a notes app or text editor. Check whether actual words appear rather than a blank result or an image.
  • Search for a word. Use the viewer's Find command for a word that is clearly visible on the page. A result is a useful sign that searchable text exists.
  • Check more than one page. Some PDFs combine normal digital pages with scanned attachments. One page may allow selection while another does not.

These are practical clues, not a perfect test. A scanned document may already have an OCR text layer, and a PDF with unusual fonts or encoding may still be difficult to copy even when it contains text.

How to extract text from a scanned PDF using OCR

If a page is only an image, run OCR with a trusted application or service before extracting its text. OCR adds a recognised text layer to the scanned document or converts the page image into editable text. The exact steps depend on the software you use.

Option 1: Recognise text in Adobe Acrobat

  1. Open a copy of the scanned PDF in Adobe Acrobat.
  2. Choose All tools, then Scan & OCR.
  3. Select In this file.
  4. Choose the page range and the language used in the document.
  5. Select Recognize Text and let Acrobat process the pages.
  6. Save a new searchable PDF. Review the recognised words before relying on them.

Adobe explains that a scanned PDF can contain image data rather than searchable words, and that OCR creates a searchable text layer. See Adobe's instructions for recognising text in scanned PDFs.

Once you have saved the searchable copy, open that copy with the QuickTools24 Extract PDF Text tool and create the TXT file.

Option 2: Use Google Drive for a simple text conversion

Google Drive can convert supported PDF and image files into text by opening a file with Google Docs. In Drive on a computer, right-click the file and choose Open with → Google Docs. Google notes that the source file should be 2 MB or smaller for its documented conversion workflow.

For better recognition, Google recommends an upright document, clear contrast, even lighting and text at least 10 pixels high. This method may not preserve the original layout: lists, tables, columns, footnotes and endnotes may not be recognised as expected. Read Google's PDF and photo-to-text guidance before using this option.

Privacy reminder: Google Drive is a separate third-party service. Use it only for files you are allowed to place in that service and when its privacy and data-handling terms suit your document. Do not upload confidential records to an unfamiliar OCR website.

Tips for more accurate text recognition

  • Use a sharp scan. Blurry letters, shadows and low contrast make characters harder for OCR to identify.
  • Straighten the page. Rotate a sideways scan before recognition. Keep lines horizontal and avoid cutting off the edges.
  • Choose the correct language. OCR needs the right language setting to distinguish similar characters and accents.
  • Use the clearest available source. If you can scan the original paper again, use a suitable resolution and keep the page well lit.
  • Check complex layouts manually. Columns, tables, small footnotes, stamps and handwriting may need correction after recognition.
  • Verify important details. Compare names, dates, reference numbers, amounts and other critical information with the page image.

Why might the extracted text be blank or incorrect?

The TXT file is empty or missing some pages

The PDF may contain image-only pages, or the file may mix text and scanned pages. Test whether you can select words on the missing pages. Run OCR on those pages if they do not contain a text layer, then try extraction again.

Words appear in the wrong order

PDFs are designed to display pages, not necessarily to store sentences in the same order you would read them. Multi-column layouts, sidebars, tables and text boxes can produce a plain-text result that looks jumbled. Use the original PDF to confirm the intended reading order.

Some characters are replaced or missing

Unusual font encoding, low-quality scans, mixed languages or OCR mistakes can affect the output. Try another copy of the source or repeat OCR with the correct language. Do not assume a number or name is correct without checking it.

The PDF cannot be processed

Confirm that the file opens in a PDF viewer and is not damaged. Some documents restrict copying or extraction. Only work with files you are authorised to access, and follow the document owner's password and permission requirements.

Frequently asked questions

Can QuickTools24 extract text from a scanned PDF?

The QuickTools24 Extract PDF Text tool reads text already available in the PDF. It does not perform OCR on page images. Run OCR first, save a searchable copy and then try text extraction again.

How do I know whether a PDF contains selectable text?

Try selecting and copying a sentence or searching for a visible word in your PDF viewer. If the words cannot be selected or found, the page may be an image scan without a text layer.

Does extracting text keep the original PDF formatting?

No. QuickTools24 creates a plain TXT file. Fonts, colours, exact spacing, columns and table layouts are not preserved, so check the text against the original PDF.

Can I extract PDF text on a mobile phone?

Yes. Open the tool in an up-to-date mobile browser and select the PDF from your device. Large or complex files may take longer and depend on available device memory.

Will OCR recognise every word correctly?

No OCR system is perfect. Blurry scans, skewed pages, handwriting, unusual fonts and complex tables can cause errors. Review important details against the page image.

Does text extraction change my original PDF?

The QuickTools24 tool produces a separate TXT result. Keep your original PDF until you have checked the extracted text and saved any corrected copy you need.
