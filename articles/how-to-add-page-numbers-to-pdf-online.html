How to Add Page Numbers to a PDF Online: Position, Format and Page Range

A long PDF is easier to reference when every page has a clear number. Page numbers help people follow instructions, discuss a particular page and keep printed copies in order. The important part is choosing a numbering range and position that do not cover the document's existing content.

This guide explains how to add visible page numbers with the QuickTools24 PDF tool, how to leave a cover page unnumbered, and what to check before sharing the new file.

Go straight to the tool: Open QuickTools24 Add Page Numbers to place numbers at the top, middle or bottom of your PDF, choose a number format, and set the first and last pages to number.

1. Decide how the document should be numbered

Before editing, decide whether numbering should start on the first physical PDF page or after a cover page. Also check whether the file already contains printed numbers in a header or footer. Adding a second set can make the page confusing.

For a straightforward report, a common approach is to number every page from 1 and place the number consistently in the bottom margin. For a document with a cover page, you may prefer to leave that first sheet without a visible number and start the visible sequence on the next page.

Some formal documents use different systems for different sections, such as Roman numerals for preliminary pages and Arabic numerals for the main text. Decide whether your task needs a simple visible number on each page or a more advanced section-based numbering system before choosing a tool.

2. Add page numbers with QuickTools24

  1. Open the tool. Visit the Add Page Numbers page and select Open Add Page Numbers.
  2. Select your PDF. Choose the document from your phone, tablet or computer. The current PDF limit is 25 MB per file and 300 pages.
  3. Choose a numbering format. Standard page number prints the running number. Custom format lets you add text around the number using the supported tokens described below.
  4. Choose a position. Pick top, middle or bottom, aligned left, centre or right. Bottom-centre and bottom-right are common choices, but the best position depends on the page layout.
  5. Set the appearance. Choose a font size and text colour that remain readable without competing with the document.
  6. Set the page range. Enter the first physical PDF page that should receive a number. Set the last page to 0 to continue through the end, or enter a final page number to stop earlier.
  7. Process and download. Run the tool, download the updated PDF, then open the downloaded file and inspect the numbering on the first, middle and final numbered pages.

3. Understand the format options

The standard format prints the running number by itself, such as 1, 2, 3 and 4. Choose Custom format when you want a label around the number. QuickTools24 supports these two placeholders:

PlaceholderWhat it printsExample
{NUM}The running number for the current page.With the pattern Page {NUM}, the page may show “Page 3”.
{CNT}The total number of physical pages in the PDF file.With Page {NUM} of {CNT} in a 12-page PDF, the last page shows “Page 12 of 12” when all pages are numbered.

You can include ordinary text, punctuation and spaces around the placeholders. For example, Page {NUM} of {CNT} creates a “Page 1 of 12” style label. The total-page placeholder refers to the full PDF page count, even when you choose to number only part of the file.

4. Leave a cover page unnumbered

Suppose a report has 12 physical PDF pages and its first page is a cover. To start visible numbering on the second physical page:

  • Set First page to number to 2.
  • Set Last page to 0 to continue to the end.
  • Use the standard format, or a custom pattern such as Page {NUM}.

The number printed on physical page 2 will be 1, page 3 will be 2, and so on. If you use {CNT}, it will still show the total physical page count of the PDF, including the cover. This is useful to know when checking a document with an unnumbered front page.

5. Choose a readable position and appearance

Page numbers should be easy to find but should not compete with the main content. Use the same position throughout a document, and check the area near the bottom or top edge for existing footers, signatures, tables or important notes.

  • Position: bottom-centre is a familiar choice for reports. Bottom-right may suit documents with a centred footer. Choose a top position when the bottom margin is already busy.
  • Font size: start with a modest size and inspect it at normal viewing scale. It should be readable on a phone and on a printed page.
  • Colour: dark text usually offers better contrast on a light page. Avoid a colour that blends into the document background.
  • Consistency: do not move numbers between corners from one page to the next unless the document's layout specifically requires it.

Adobe's current guide to adding PDF page numbers also recommends selecting the number format and starting page, choosing a header or footer location, and checking the preview before saving.

6. Check the finished PDF carefully

Do not rely only on the first page. Open the downloaded file in a PDF viewer and check:

  • The cover page is either numbered or left blank as planned.
  • The sequence increases by one on every numbered page and stops on the intended last page.
  • Numbers are not hidden by existing footers, signatures, stamps, tables or page content.
  • Numbers are visible on both portrait and landscape pages, if the document mixes page orientations.
  • The downloaded PDF still opens and its text and images remain readable.

For a very long document, you can first use PDF Information to check its page count. If the final document needs pages combined or rearranged, do that first with Merge PDF or Reorder PDF Pages, then add the page numbers to the final page order. To remove unwanted pages before numbering, use Delete PDF Pages or Extract PDF Pages.

7. Visible page numbers are not the same as PDF page labels

There is an important technical difference between text printed on a page and the page labels used by a PDF viewer's navigation controls. The QuickTools24 tool draws visible number text onto each selected PDF page. It does not rewrite the PDF's internal page-label information.

The W3C PDF17 technique explains why consistent page labels can help people locate themselves in a document, including PDFs whose preliminary pages use Roman numerals and whose main text starts again at 1. If a court, regulator, publisher or accessibility workflow requires the viewer's navigation labels to match a formal numbering scheme, use a PDF editor that supports page labels or set the numbering in the original document before exporting it to PDF.

Important: QuickTools24 adds a visible number. It does not automatically create Roman numerals, restart numbering at multiple sections, change the viewer's page-navigation labels, or remove numbers that are already printed on the page. Check the receiving organisation's exact instructions for formal submissions.

Frequently asked questions

Can I leave the cover page unnumbered?

Yes. Set First page to number to 2. The first visible number will be 1 on the PDF's second physical page. Set Last page to 0 to continue through the end of the file.

Can I put page numbers at the top or bottom?

Yes. QuickTools24 offers nine positions: top, middle or bottom, each aligned left, centre or right.

What do {NUM} and {CNT} mean?

{NUM} is the running number printed on the current page. {CNT} is the total number of physical pages in the PDF file.

Does adding a visible number change the page number shown in a PDF viewer?

No. The tool draws visible number text on the page. It does not change the PDF's internal page labels used by some viewer navigation controls.

Can the tool remove page numbers already printed in a PDF?

No. It adds a new visible number and does not erase old printed numbers. Check the source document first if it already has a footer or page number.

What are the PDF limits?

The current PDF limit is up to 25 MB per file and 300 pages. Large documents can take longer and depend on available device memory.
