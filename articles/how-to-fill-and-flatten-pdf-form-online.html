How to Fill and Flatten a PDF Form Online

Some PDFs contain fields you can type into. Others are simply scans or printed forms saved as page images. Knowing the difference helps you choose the right tool—and avoid downloading a file that looks complete but still has blank or editable fields.

This guide explains how to fill supported interactive fields with QuickTools24, what to do when a form is not fillable, and when it makes sense to flatten a completed PDF.

Choose the right starting point: Use Fill PDF Form Fields when your PDF already contains interactive fields. After checking the completed file, use Flatten PDF Forms only when you want those fields to stop behaving like editable form controls.

Interactive PDF forms and flat forms are different

An interactive PDF form contains named fields such as text boxes, dropdowns, radio groups or checkboxes. A PDF viewer can recognise those controls and let a person enter a value. These forms are often called AcroForms.

A flat form has no interactive fields. It may be a scan of a paper form or a PDF where the form was printed or saved as ordinary page content. The boxes and labels are visible, but there is no field object for a form-filling tool to update. Adobe describes these as flat forms and recommends a text or Fill & Sign workflow for adding information to them.

How to fill an interactive PDF form with QuickTools24

  1. Keep an untouched copy. Save the original PDF before editing. This gives you a clean version to return to if a field value or appearance needs correcting.
  2. Open the Fill PDF Form Fields page. Go to QuickTools24 Fill PDF Form Fields and open its workspace.
  3. Select your PDF. Choose the file from your phone or computer. The current tool limit is 25 MB per PDF and 300 pages. Allow the document preview and field scan to finish.
  4. Check the detected field names. The workspace reports how many interactive fields it found and offers field-name suggestions. Copy the full name exactly, including dots or brackets if they appear in the name.
  5. Enter one field and its value. Put the field name in Form field name and the information in Field value. The current QuickTools24 form tool handles one named field per processing run.
  6. Process and download. Select Process PDF and download the new document when it is ready.
  7. Repeat for another field if needed. To fill a second field, open the downloaded result in the same tool, choose the next detected field name, enter its value and process it again. This step-by-step approach keeps each change in a separate saved copy.
  8. Review the completed document. Reopen the latest output and inspect every value, especially dates, long names, numbers, dropdown choices and checkboxes.

Which value should you enter?

The value depends on the field type. Use the field name suggested by the workspace, then provide a value that the field can accept.

Do not guess a field name. If the tool says that a field does not exist, return to the detected field list and copy the complete name again. Some PDFs use technical names that do not match the printed label on the page.

How to flatten a completed PDF form

Flattening is optional. It is useful when you want the current visible field values to become part of the page content rather than remain interactive controls. It is not required just to save a filled PDF.

  1. Finish filling the form and save the latest output.
  2. Open QuickTools24 Flatten PDF Forms.
  3. Select the completed PDF and choose Process PDF.
  4. Download the flattened file, open it again and check that every value is visible on the correct page.

When a PDF is flattened, the current appearance of its form fields is placed into the page content and the interactive field controls are removed. The values remain visible, but you can no longer edit them as form fields. Keep the original editable version if you may need to make changes later.

What if the PDF has no interactive fields?

If QuickTools24 reports that no interactive form fields were found, the document may be a flat form or a scan. The Fill PDF Form Fields tool cannot create fields that are not already in the PDF.

For a flat form, open Add Text to PDF, select the document and use the page preview to choose where the text should appear. Process the file, then zoom in and check that each entry lines up with the correct printed box. For a visual handwritten or typed signature, see Add Signature to PDF. A visual signature tool is not a substitute for a certificate-based digital-signature process when one is required.

Common problems and sensible checks

  • No fields are detected: The PDF may be flat or scanned. Use a manual text-placement tool instead of repeatedly trying to fill non-existent fields.
  • The field name is rejected: Copy the full name shown in the suggestions. Do not substitute the visible label unless it is also the actual field name.
  • A dropdown value is rejected: Enter a choice that belongs to the field's available options. Check spelling and punctuation.
  • Text is clipped or looks wrong: Keep entries concise where possible and inspect the saved page at normal reading size and at higher zoom.
  • Hindi or other non-Latin text is not displayed correctly: Check the output before using it. The current form tool relies on the PDF library's default Helvetica/WinAnsi appearance path when it updates changed fields; that default does not cover every writing system. Use a form editor with suitable font support if the required characters are missing or damaged.
  • The file will not process: Check that it is a valid, unlocked PDF within the stated size and page limits. Large files may also need more memory than a phone browser has available.
Do not flatten too early. Flatten only after you have checked every value. Once flattened, the form fields are no longer editable as form controls. Keep an untouched original, especially for official, financial or legally important documents.

Frequently asked questions

Can I fill every field in one step?

The current QuickTools24 Fill PDF Form Fields workspace asks for one field name and one value per processing run. Download the result and use that output as the input for the next field you need to fill.

Can I fill a form by tapping the printed boxes?

Not with the interactive form tool. It updates fields by their detected names. For a scanned or flat form, use Add Text to PDF to place text manually on the page.

Does flattening remove the values I entered?

Flattening is intended to keep the current field appearance visible in the page content while removing the interactive form controls. Always open the downloaded file and verify the values before sharing it.

Does flattening make a PDF secure?

No. Flattening is not password protection, encryption, redaction or a guarantee against copying. Use the correct security or redaction process for the document and recipient requirements.

Can I use these tools on a phone?

Yes, you can open the tools in an up-to-date mobile browser. Large or complex PDFs may take longer and depend on the memory available on your device.

Will Hindi text always appear correctly in a form field?

Not necessarily. The current form appearance path uses the PDF library's default Helvetica/WinAnsi font behaviour when saving changed fields. Check non-Latin text carefully and use a font-capable editor if characters are missing or incorrect.
