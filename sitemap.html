Finding the right tool

Start with the category that matches your task. PDF tools help with combining documents, splitting pages, reducing file size and editing supported page elements. Image tools help prepare photos and graphics by cropping, resizing, compressing or changing file formats. The guides section provides step-by-step explanations for common tasks.

If you are preparing a file for an online form, check the form's own instructions for accepted formats, dimensions and maximum file size. A converted or compressed file should always be opened and checked before you upload it. Keep an original copy until the receiving website confirms that the file has been accepted.
