How to use the QuickTools24 PDF editor

Open a PDF in the editor, wait for its pages to load, and select the page you want to work on. Use the available tools to add text, place an image, draw a signature or add shapes and annotations. Move added objects into position and review the page at a readable zoom level before exporting.

Important note about existing text

Adding text or images creates new content on top of the PDF page. Covering old text with a white shape and placing replacement text over it is an overlay technique; it does not necessarily remove the original text from the underlying PDF content. Do not use this method for secure redaction of confidential information.

Review the exported PDF

Download the edited copy and open it in a separate PDF reader. Check every changed page, the position of text and signatures, and whether the document still prints correctly. Keep an untouched copy of the original file until the edited version has been verified.

Related tools

If you only need to combine documents, use Merge PDF. To separate pages, use Split PDF. To reduce a large file, try Compress PDF and inspect the result for quality.

Privacy and file limits

Your selected PDF is processed in your browser. QuickTools24 does not intentionally upload document contents to its own file-processing server. Third-party libraries, analytics and advertising resources may receive normal connection or usage information.

PDF files are limited to 25 MB and 300 pages in the shared processing engine. Browser memory and device performance can affect larger documents.

Properties

Existing text replacement is visual: the old area is covered and replacement text is drawn. PDF text layer is detected; image-only scanned PDFs need OCR and are not directly editable.
