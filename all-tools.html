How to choose the right online tool

Start with the result you need rather than the file type alone. To combine documents, choose Merge PDF. To save only selected pages, choose Split PDF. To reduce a document's upload size, try the PDF compressor and check the downloaded file before submitting it.

PDF and image tasks

PDF tools are useful for arranging, converting and preparing documents. Image tools help prepare photos for forms, websites, email and everyday sharing. If a website specifies both pixel dimensions and a maximum KB size, check both requirements after processing.

Calculators and converters

Use the calculators for common arithmetic, percentages, GST, discounts, loan EMI, interest, averages and age calculations. Unit converters help compare measurements such as length, weight, temperature, area, volume, speed, time and digital storage. Check the units and inputs before relying on a result.

Helpful guides
