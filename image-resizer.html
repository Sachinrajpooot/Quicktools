Choose the right image dimensions

Image dimensions are measured in pixels: width is the horizontal measurement and height is the vertical measurement. Resizing is useful for profile photos, website images, online forms and documents that request a specific pixel size.

Keep the image proportions

Most photos have a width-to-height ratio. If you change width and height independently, people or objects can look stretched. When the destination does not specify both dimensions, preserve the original proportions and crop only when the required shape is different.

Pixels are not the same as file size

A smaller pixel width and height often reduce file size, but the final KB or MB value also depends on the image format and compression quality. If a form asks for a maximum file size, check the downloaded file after resizing. You can use the Image Compressor or Photo Size Reducer for further size reduction.

Quick checklist

  • Read the destination's width and height requirements.
  • Check whether it requires JPG, PNG or another format.
  • Preview the result before uploading.
  • Keep the original image as a backup.
