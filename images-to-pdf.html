Prepare images before creating a PDF

For a multi-page PDF, select the pictures in the order they should appear. This is useful for combining scanned pages, receipts, screenshots or application documents. Open the finished PDF and check that the first page, last page and every page in between are in the correct sequence.

Choose a page size and fitting option

Use the page size requested by the organisation receiving your document. A4 is common for office paperwork, but it is not suitable for every task. Choose a fitting option that preserves the original image proportions so that text and signatures are not stretched or cut off.

Will the PDF be searchable?

A PDF created from pictures usually contains the pictures as page images. Text inside a scanned image may not be selectable or searchable unless OCR is applied separately. If you need editable text, use an OCR or document-conversion workflow and review the result carefully.

Check the final file

Image-heavy PDFs can be large. Converting images to PDF does not guarantee a smaller file. If an upload limit applies, check the final size and try the PDF Compressor if needed. Keep your original images until the PDF has been accepted.
