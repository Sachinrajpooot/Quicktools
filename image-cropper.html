Choose crop dimensions carefully

The X and Y values describe the crop's starting point from the image's top-left corner. Width and height describe how large the selected area should be, in pixels. Keep the crop inside the original image boundaries. If the preview or result looks empty, reduce the crop width or height or move the starting point closer to the top-left.

Keep the subject and important details

Before saving, check that faces, signatures, document numbers and other important details are not cut off. A square crop works for many profile pictures, while a wider crop can suit banners. If a website specifies exact dimensions or an aspect ratio, follow those requirements rather than guessing.

Does cropping reduce image size?

Removing pixels can reduce the amount of image data, but the final file size also depends on the output format and encoding. Cropping is not a guaranteed way to reach a specific KB limit. For a file-size target, use the Photo Size Reducer or Image Compressor after cropping, then check the saved file.
