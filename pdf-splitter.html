Ways to split a PDF

Splitting a PDF helps when you need to share only a few pages, separate chapters, or create smaller files for an upload. Decide whether you need individual pages, a continuous page range or several smaller documents before processing.

Check page numbers carefully

  • Open the PDF and confirm its page count.
  • Use the page numbers shown by the PDF viewer, not a printed page number inside the document.
  • For a range, confirm both the first and last page.
  • Open each output file to verify that no required page is missing.

What if a split file is too large?

Try a smaller page range or use the PDF compressor if the document contains large images. If you need to join the output files later, use Merge PDF.

Keep the source document until you have checked every exported file. Splitting creates separate copies; it should not be treated as a replacement for your original.
